# racecat
# 🐱 赛程猫 Saichengmao

一个面向大学生备赛/备考的极简 Deadline 驱动任务工具。

## 核心理念

不是告诉你“有哪些事情没做”。

而是告诉你：

> 今天最值得做什么？

## Features

- [x] 赛程倒计时
- [x] 任务管理
- [x] 每日任务推荐
- [x] 任务完成记录
- [ ] 动态任务调整
- [ ] 用户行为分析
- [ ] 个性化推荐
